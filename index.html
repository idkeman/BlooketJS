BlooketJS.

A JavaScript wrapper concept for interacting with Blooket game sessions. This page collects the project overview, the original example, and the current implementation status in one place.

Important: work in progress. The repository currently has no published source implementation or package manifest. The API shown below comes from the README and has not been verified as working. Do not assume that installation, authentication, or game actions currently succeed.
JavaScript

Node-oriented

The README demonstrates a Node.js-style client using CommonJS and an environment variable for a token.

Event-driven

Client events

The proposed interface uses events for readiness, joining, incoming questions, and game completion.

Experimental

Not production-ready

Blooket may change its private services at any time. Compatibility and permission boundaries are not established.

Quick start example

This is a cleaned-up version of the usage pattern in the repository README—not a tested installation guide.

const { Client } = require("blooketjs"); const client = new Client({ token: process.env.BLOOKET_TOKEN }); client.on("ready", () => { console.log("Client is ready"); }); client.on("join", () => { console.log("Joined the game"); }); client.on("question", question => { console.log("Question received:", question); }); client.on("end", () => { console.log("The game has ended"); }); client.join(123456, "ExampleName");
  • The README does not provide a working package installation command or published package version.
  • Never place account tokens in browser JavaScript, public repositories, or client-side HTML.
  • Only test against accounts and sessions you are authorized to use; avoid automation that disrupts other players or bypasses game rules.
