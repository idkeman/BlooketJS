Connect to live Blooket games.

Player joining, host creation, and set creation in one workspace. The connector uses an older community wrapper, so every live operation is reported honestly and may need compatibility updates.

Join a live game

Join as one regular player. This does not create extra accounts or automate answers.

The upstream wrapper sends WebSocket join messages to multiple legacy server ranges and reports “Joined” before it receives a server acknowledgement. A successful response here means the request was sent, not that Blooket confirmed entry. Verify the player appears in the live lobby.

Create a hosted game

Create a game from a Blooket set using your own account authorization token.

Never paste your account password. This token is sent to the API backend you configure, and is not saved by this page. Only use a backend you control.
Blooket has no public, stable host API. This uses the community wrapper's undocumented host endpoint. It may stop working when Blooket changes its service.

Create a question set

Create a new set shell in your account. The upstream wrapper does not implement adding questions or editing a set.

Question editing and image uploads are not implemented by this upstream library. The connector will not claim those features are available.

Backend connection

The website is static; live Blooket requests run on a separate Node service.

Paste your published Replit backend URL here.
The API URL is saved in this browser. Account tokens are never saved in local storage. The backend should be deployed by you and restricted to your website origin.
