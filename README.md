# BlooketJS — Railway connector foundation

This repository contains two parts:

- `index.html`: the static dashboard published through GitHub Pages.
- `server.js`: a small Node.js/Express API intended to run as a Railway service.

The backend is deliberately limited to health and integration-status checks. Blooket's published Terms of Service prohibit unauthorized bots, reverse-engineering, hacks, and software that changes or facilitates gameplay. The old community-wrapper calls to private/undocumented Blooket endpoints have therefore been removed. Do not add live-game operations unless Blooket explicitly authorizes the integration.

## Deploy the backend on Railway

1. Sign in to [Railway](https://railway.com/).
2. Choose **New Project** → **Deploy from GitHub repo**.
3. Select `idkeman/BlooketJS` and the `main` branch.
4. Deploy from the repository root. Railway detects Node.js from `package.json` and uses the `npm start` script.
5. Open the new service's **Settings** → **Networking** and generate a public domain.
6. In the service's deployment settings, set the healthcheck path to `/api/health` if it is not detected automatically.
7. Add this service variable:

   ```text
   ALLOWED_ORIGINS=https://idkeman.github.io
   ```

8. Redeploy if Railway asks you to apply the variable.

Railway supplies the `PORT` environment variable automatically. The Express server listens on `0.0.0.0` and uses that port; do not hardcode a public port.

After deployment, visit:

- `https://YOUR-RAILWAY-DOMAIN/`
- `https://YOUR-RAILWAY-DOMAIN/api/health`
- `https://YOUR-RAILWAY-DOMAIN/api/integration/status`

The health endpoint should return JSON with `"ok": true`.

## Connect the GitHub Pages dashboard

1. Open [BlooketJS](https://idkeman.github.io/BlooketJS/).
2. Paste the HTTPS domain generated by Railway into **Railway API base URL**.
3. Select **Save and test connection**.
4. The dashboard should report that the Railway backend is online. It will also report that Blooket live-game integration is not authorized/configured.

The dashboard saves only the Railway URL in the current browser. It does not request or store Blooket passwords, cookies, or authorization tokens.

## Local development

Requires Node.js 20 or later.

```sh
npm install
npm start
```

Run validation:

```sh
npm run check
npm test
```

The API listens on port 3000 locally unless `PORT` is set. For a local frontend, add its exact origin to `ALLOWED_ORIGINS`.

## API endpoints

| Method | Path | Purpose |
|---|---|---|
| GET | `/` | Service metadata |
| GET | `/api/health` | Railway deployment health check |
| GET | `/api/integration/status` | Reports whether an authorized Blooket integration is configured |

Legacy `POST /api/game/join`, `POST /api/game/host`, and `POST /api/sets` routes return HTTP 501. They do not send requests to Blooket.
